# 📘 SQL Course Notes (QSpiders)

This repository contains complete **SQL course notes** and assignments from QSpiders, covering everything from database basics to advanced SQL operations.  
It is intended for students or self-learners who want to strengthen their SQL fundamentals with clear examples and practice problems.

---

## 📚 Course Overview
Structured Query Language (**SQL**) is used to interact with and manage data stored in relational databases.  
This course explains every concept step-by-step with examples, syntax, and practical exercises.

---

## 🧩 Topics Covered
### 🔹 Day 1 – Introduction to Databases
- What is Data, Database, DBMS, RDBMS  
- CRUD Operations: Create, Read, Update, Delete  

### 🔹 Day 2 – Data Types
- `CHAR`, `VARCHAR`, `VARCHAR2`, `NUMBER`, `DATE`, `CLOB`, `BLOB`  

### 🔹 Day 3 – Constraints
- `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, `CHECK`  

### 🔹 Day 4 – SQL Commands
- `CREATE`, `INSERT`, `UPDATE`, `DELETE`, `SELECT`  
- DDL, DML, DQL, TCL, DCL  

### 🔹 Day 5 – SELECT & WHERE Clauses
- Filtering data using `WHERE`, `BETWEEN`, `IN`, `LIKE`, `NOT IN`  

### 🔹 Day 6 – Operators & Expressions
- Arithmetic, Logical, Comparison, and Concatenation Operators  

### 🔹 Day 7 – Functions
- **Single-Row Functions** (String, Numeric, Date)  
- **Aggregate Functions** (`SUM`, `AVG`, `COUNT`, `MAX`, `MIN`)  

### 🔹 Day 8 – Joins & Subqueries
- Inner, Outer, Self, and Cross Joins  
- Nested and Correlated Subqueries  

### 🔹 Day 9 – Transactions & Views
- `COMMIT`, `ROLLBACK`, `SAVEPOINT`  
- Creating and Managing Views  

---

## 🧠 Assignments
Each module includes practice problems such as:
- Writing queries using different clauses  
- Applying constraints and joins  
- Using functions for calculations  
- Working with multiple tables
